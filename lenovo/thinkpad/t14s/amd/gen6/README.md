# Thinkpad T14s Gen 6 (AMD)

There are two variants of this laptop. The only substantial difference appears to be the Wi-Fi chipset.

* Strix Point, models 21M1 and 21M2, with the Ryzen AI 7 PRO 360 CPU and Qualcomm NCM825 Wi-Fi.
* Krackan Point, models 21TB and 21TC, with the Ryzen AI 7 PRO 340/350 CPU and MediaTek MT7925 Wi-Fi.

This module has only been tested on a Krackan Point/MediaTek device.

Use the base module for Strix Point; use `krackan-point` variant for that platform.
